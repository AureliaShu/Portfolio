GT Movies Store Project

A Django-based web application where users can create accounts, browse and search for movies, manage shopping carts, purchase items, post and modify reviews.

Project Description

GT Movies Store contains seven core features:

Feature Details
Home Page The main page that introduces the application. The Top Navigation Bar provides a quick routing to About, Movies, Cart, and Login/Sign Up pages.
Login / Sign Up Page The authentication system that allows new users to register and existing users to log in. Some operations require login to proceed.
Browse & Search Movies A page where users can explore and search for movies. Information like the price, summary, and reviews of each movie will be displayed.
Create & Modify Reviews The logged-in users are able to write, edit, and delete their reviews of movies. Users are also allowed to report inappropriate reviews.
Manage Carts The users can add or clear movie items in their cart. The current total price will be displayed on the cart page.
Purchase Items A checkout system that enables the users to purchase movies.
View Orders A dashboard where users can see their order history and details.

Development Process

Setup & Structural Planning

I divided the project into four Django apps (home, accounts, movies, and cart). Having different models and functions, each app has separated responsibilities.

Backend User Stories Mapping

Based on user stories, I designed the details of models, like the logic of reporting and hiding reviews.

Frontend Template Rendering

For a clean and interactive UI, I rendered buttons and other control elements by using HTML.

Testing and Debugging

I tested core features on the browser, and debugged relevant code by checking for syntax, path, and logic errors.
